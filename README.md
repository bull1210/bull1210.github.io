# bull1210.github.io

The PixOrg website (https://bull1210.github.io): a home page, guides, `app-ads.txt` for AdMob, built by
GitHub Pages from `main` with Jekyll (no local build needed).

- `_guides/*.md`: one guide per search question; rules in `STYLE.md`.
- `tools/seo/gaps.py`: finds queries Search Console shows but no guide answers, from CSV exports in `data/gsc/`.
- `tools/seo/ROUTINE.md`: the weekly agent's brief: one guide, one pull request, never a direct publish.
- `app-ads.txt`: AdMob and Liftoff authorised sellers. Do not move it.
- The privacy policy lives in `bull1210/pixorg-privacy` (https://bull1210.github.io/pixorg-privacy/privacy-policy.html).

Search Console: paste the HTML-tag token into `google_site_verification:` in `_config.yml`.
